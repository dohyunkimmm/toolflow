# ToolFlow 카드 기준

참고: https://www.jobplanet.co.kr/job (2026-10-24 연결 브라우저에서 확인)

관찰한 공고 카드: PC 3열, 링크 영역 382×148px, 안쪽 여백 16px 20px 20px. 작은 로고·이름, 한 줄 제목, 짧은 부가 정보, 아래 태그와 오른쪽 작은 테두리 버튼으로 구성되어 있습니다. 모바일 형태는 참고 페이지에서 별도로 검증하지 않았습니다.

ToolFlow 적용: 상단 조건 영역에는 직군 선택·신청 상태만 두고, 도구 검색·AI 추천은 검색 행에 배치합니다. 검색 입력칸은 폭을 제한한 보조 요소로 두고, AI 추천은 더 넓은 파란 주요 버튼으로 강조하며 모바일에서도 함께 읽히도록 배치합니다. 업무 유형·필수/선택·정렬 드롭다운은 사용하지 않습니다. 카드에는 도구 로고·이름 → 한 줄 용도 → 담당 부서·처리 기간 → 작은 필수/선택·상태 태그와 하단 오른쪽 신청/사용 안내. 업무 도구의 상태 정보를 포함해 기본 최소 높이 176px(560px 이하 모바일 160px)로 적용합니다. PC 3열, 태블릿 2열, 모바일 1열을 사용합니다. 신청 버튼은 카드 폭을 채우지 않습니다. 모바일 버튼 높이는 터치 조작을 위해 44px로 유지합니다. 카드 제목은 약 15.5px, 담당·처리 기간은 12.5px 이상으로 정돈하고 신청 버튼도 44px 터치 영역을 유지합니다. 상태 필터는 검색 행의 폭에 맞춰 지나치게 늘어나지 않게 하고, 320px 화면에서도 검색 문구가 잘리지 않도록 합니다. 로그인 완료 토스트는 첫 카드 가림을 막기 위해 생략합니다.


2026-10-25 최신 QA: [PR #160–#162](https://github.com/dohyunkimmm/toolflow/pull/162)로 데스크톱 제목·검색·필터·카드의 왼쪽 정렬, 모바일 검토자 한 줄 헤더 및 320×568px·390×667px 조작성·첫 카드 노출을 보정했습니다. [최종 운영 E2E 13/13 성공](https://github.com/dohyunkimmm/toolflow/actions/runs/40193714768). '10/10'은 정의된 QA 검사 통과이며 절대적인 미적 점수가 아닙니다.

문자: 자체 제공 Pretendard Variable. UI 아이콘: 토스페이스 공식 원본 SVG(변형 없음). SaaS 로고는 각 기존 브랜드 자산을 유지합니다. 토스페이스 출처·라이선스는 fonts/TOSSFACE-NOTICE.txt 및 fonts/TOSSFACE-LICENSE.txt에 포함합니다.

## 2026-11 디자인 시스템 고도화

이 단계에서는 신규 기능·신청 데이터·권한 상태를 변경하지 않고 시각 표현만 조정합니다.
최종 시각 규칙은 `css/design-elevation.css`로 통합하며, 기존 `catalog.css`와
`typography-qa.css`에서 중복되는 주요 브랜드 색상은 동일한 CSS 변수로 참조합니다.
과거 버전의 CSS 규칙은 기능 회귀를 막기 위해 즉시 일괄 삭제하지 않습니다.

- **색상:** 주요 동작 `#2459C2`, 호버 `#194AA8`, 보조 배경 `#EDF3FF`, 본문 `#17253D`, 페이지 `#F7F9FC`, 구분선 `#E2E8F0`. 상태 색상은 파랑(필수), 녹색(사용 가능·완료), 노랑(검토 대기), 빨강(반려·예외)으로 분리하며 **텍스트 라벨도 함께 노출**합니다.
- **카드:** 기존 PC 3열·태블릿 2열·모바일 1열을 유지합니다. 제목·용도·처리 정보·상태·동작 순서를 유지하며 여백, 경계, 호버, 키보드 포커스를 통일합니다.
- **탐색:** 검색과 AI 추천의 기존 비율을 유지하여 모바일에서 높이가 불필요하게 늘어나지 않도록 합니다. 320px에서는 첫 카드 노출을 우선하여 소개 문구를 숨깁니다.
- **로그인과 오버레이:** 같은 배경·경계·버튼·문자 계열을 사용하고, 로그인 글꼴 안정성 규칙과 모달의 가용 높이·고정 제출 영역은 유지합니다.
- **접근성:** 포커스 표시, 상태별 텍스트, 대비, 44px 이상 주요 터치 영역, reduced-motion 및 forced-colors 대응을 유지합니다. 색상 대비는 실제 브라우저의 axe/Playwright 실행 결과로 최종 확인합니다.
- **시각 검증(2026-11-10 확정):** `tests/visual-baseline.spec.js-snapshots/`에 Chromium/Linux 고정 환경의 PNG 기준 이미지 **9장**을 보존합니다. 로그인(1440·390·320px), 카탈로그 첫 화면(1440·390·320px), 신청 모달(1440·390px), 검토자 패널(1440px)이 대상입니다. 서로 독립적인 두 번의 생성에서 9개 PNG의 SHA-256 및 픽셀이 모두 동일했습니다. `npm run test:visual:baseline`이 CI에서 새 렌더링과 고정 이미지를 비교하고, 화면 회귀가 발생하면 실패 및 차이 이미지 증빙을 남깁니다. 원래 시각 캡처와 기존 기능·접근성·모바일 검사는 별도로 유지하며, 디자인 변경 시 기준 이미지는 검토 후에만 갱신합니다.

영향 범위: `index.html`, `css/design-elevation.css`, `css/catalog.css`,
`css/typography-qa.css`, 디자인·레이아웃 Playwright 검사 및 무결성 자산 목록.
