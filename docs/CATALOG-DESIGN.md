# ToolFlow 카드 기준

참고: https://www.jobplanet.co.kr/job (2026-10-24 연결 브라우저에서 확인)

관찰한 공고 카드: PC 3열, 링크 영역 382×148px, 안쪽 여백 16px 20px 20px. 작은 로고·이름, 한 줄 제목, 짧은 부가 정보, 아래 태그와 오른쪽 작은 테두리 버튼으로 구성되어 있습니다. 모바일 형태는 참고 페이지에서 별도로 검증하지 않았습니다.

ToolFlow 적용: 기본 탐색에는 직군 선택·검색·AI 추천·신청 상태만 유지하고 업무 유형·필수/선택·정렬 드롭다운은 표시하지 않습니다. 도구 검색은 간결한 입력란, AI 추천은 더 넓은 파란 주요 버튼으로 강조합니다. 카드에는 도구 로고·이름 → 짧은 용도 → 담당 부서·처리 기간 → 필수/선택·상태 태그 → 신청/사용 안내를 표시합니다. PC는 3열, 태블릿은 2열, 모바일은 1열이며 560px 이하에서 카드는 최소 160px, 신청 CTA와 상태 필터는 44px 터치 높이를 확보합니다. 카드 제목 약 15.5px, 담당·처리 정보 12.5px, 상태 배지 12px의 가독성을 기준으로 점검합니다.

2026-10-25 화면 QA: 데스크톱(1024px 이상)의 제목·검색·상태 필터·카드 **왼쪽 시작선을 통일**하고, 컨트롤 영역 최대 폭 890px 및 검색/필터 구성 폭 최대 840px을 유지합니다. 320×568px·390×667px 및 768/1024/1440px 등에서 검색 안내 잘림·가로 넘침·첫 카드 노출·버튼 접근성·필터 동작을 회귀 검사합니다. 검토자 모드에서도 모바일 헤더를 한 줄로 표시하고 도움말·신청현황의 접근성 이름을 유지합니다. 중복 로그인 완료 토스트는 첫 카드가 가려지지 않도록 제거했습니다. AI 추천 동작·색상과 신청/승인 흐름은 변경하지 않습니다.
